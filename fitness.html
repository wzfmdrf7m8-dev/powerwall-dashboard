Waiting for the first sync from your iPhone

This page fills itself in automatically once the phone starts pushing. HealthKit has no server API — data can only leave the device from an app running on it.
  1. Install Health Auto Export from the App Store and grant it read access to your Health data.
  2. Go to Automations → Add Automation → REST API.
  3. Set the URL to https://powerwall-api.randlefamily.com/hk/ingest
  4. Add a header x-api-key with your HK_TOKEN value.
  5. Format JSON, aggregation Hourly, date range Since Last Sync, frequency every 1 hour, and turn Batch Requests on.
  6. For a one-off history pull, use a second automation with a wide date range and aggregation Daily — hourly resolution over years is millions of points and will time out.
  7. Select the metrics you want — Activity, Heart, Sleep and Body are all understood, plus workouts.
Historical data: run the backfill script against your Health app export to load everything from before today.

PACE PER RUN

Every run plotted individually. Higher is faster; dot size is distance. The line is a 5-run rolling median, which is the honest read of a trend — single runs swing on weather, hills and how you slept.

VO₂ MAX vs PACE

Apple's VO₂ max estimate against your rolling pace. They should move together; if pace improves while VO₂ max is flat, the gain is likely pacing or conditions rather than aerobic fitness.

AEROBIC EFFICIENCY

Pace against average heart rate, coloured by recency. Points drifting up-and-left over time mean you are running faster at the same effort — the clearest single sign of aerobic improvement.
